Ideea

Un joc de vocabular cu ritm de concurs

13

materii selectabile: matematică, română, informatică, științe, limbi străine și altele.

14

întrebări într-o rundă standard, alese aleator doar din materiile bifate.

4 min

limită de timp pentru antrenamentul solo, cu punctaj bazat pe răspuns și ajutor folosit.

Scopul proiectului este să transforme definițiile din programa de liceu într-un format rapid, competitiv și ușor de folosit pe telefon sau desktop.

Cum se joacă

Mecanica jocului

  • Jucătorul primește o definiție și trebuie să ghicească termenul corect.
  • Răspunsul se scrie literă cu literă în căsuțe hexagonale.
  • Se pot cere litere ajutătoare, dar punctajul scade.
  • Normalizarea ignoră diferențe care nu ar trebui să blocheze răspunsul.

Fluxuri de joc

Singleplayer și multiplayer folosesc aceeași logică de întrebări

Singleplayer - /singleplayer

  • Utilizatorul alege materiile.
  • Serviciul pornește o sesiune locală în memorie.
  • Întrebările vin din QuestionSelector, filtrate pe materii.
  • Scorul, literele cerute și feedbackul se calculează imediat.

Multiplayer - /multiplayer

  • Gazda creează o cameră cu materii selectate.
  • Jucătorii intră cu cod sau QR.
  • SignalR sincronizează lobby-ul, întrebarea, răspunsurile și clasamentul.
  • Redis păstrează starea activă, iar PostgreSQL păstrează rezultatele.

Arhitectură

Web

Application

DTO-uri, opțiuni, validatori, contracte și logica de joc care nu depinde direct de baza de date.

Infrastructure

Flux server

Ce se întâmplă când pornește serverul

1

Se configurează Serilog, Razor Components, SignalR, Identity, EF Core, Redis și serviciile de joc.

2

Se activează antetele redirecționate pentru traficul venit prin Cloudflare Tunnel.

3

Rate limiting protejează login, creare cameră, join și submit answer.

4

Se mapează /health, /gameHub, /host/create, /join/{roomCode}/enter și exporturile admin.

5

La startup, migrațiile și seed-ul pot rula automat pentru baza de date.

Flux HTTP

  • Cloudflare trimite cererea către containerul web.
  • ASP.NET Core aplică middleware: erori, static files, auth, rate limiting, antiforgery.
  • Razor Components livrează interfața, iar SignalR păstrează conexiunile live.
  • Serviciile de aplicație folosesc PostgreSQL și Redis prin infrastructură.

Persistență

PostgreSQL

  • Schema este creată prin migrații EF Core.
  • Stochează utilizatori, întrebări, materii, camere, sesiuni și clasamente.
  • Seeder-ul creează date inițiale și actualizează materiile existente.
  • Exportul admin poate produce JSON sau CSV cu subiect, categorie și dificultate.

Redis

  • Păstrează starea camerelor active pentru viteză.
  • Oferă lock-uri distribuite pentru operații sensibile.
  • Poate fi backplane SignalR pentru mai multe instanțe web.
  • Rulează cu append-only persistence în Docker Compose.

Ce este important de înțeles

Nu este doar interfață

Filtrarea pe materii, scorul, validarea și selecția întrebărilor sunt în serviciile serverului.

Multiplayer real

SignalR, Redis și worker-ul de timer fac ca gazda și jucătorii să vadă aceeași stare în timp real.

Publicare local-public

Serverul rulează pe acest dispozitiv, iar Cloudflare Tunnel îl expune securizat la gravital.space.

Proiectul combină o arhitectură .NET pe straturi cu o interfață de joc rapidă și o infrastructură simplă, reproductibilă prin Docker.
